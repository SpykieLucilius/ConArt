## Reporting a vulnerability

If you find a vulnerability, please report it through the GitHub private vulnerability reporting form: `https://github.com/FatOrco/ConArt/security/advisories/new`.

> Do **not** open public GitHub issues or pull requests, file public JIRA tickets, or post to mailing lists for unpatched vulnerabilities.

If the issue is critical and requires immediate attention, please inform me directly via email at [spykie.lucilius@pm.me](mailto:spykie.lucilius@pm.me).

## Report contents

When reporting a vulnerability, please include the following information:

- Steps to reproduce the vulnerability, including any relevant code snippets or configuration files.
- Software and tool versions used when discovering the vulnerability.
- Expected and actual behavior.
- Any relevant logs or error messages.
- Any additional context that may help in understanding and reproducing the issue.

## Our response

Normally, your report will be acknowledged within 5 days, and you'll receive a more detailed response to your report within 10 days indicating the next steps in handling your submission. These timelines may extend during holiday periods, particularly at the end of the year.

## AI-assisted reports

AI-assisted reports are welcome, but please ensure that any content generated by AI tools is carefully reviewed and verified for accuracy before submission.
